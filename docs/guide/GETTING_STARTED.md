# 首次使用：从下载到第一张图

[返回项目首页](../../README.md) · [功能指南](./FEATURES.md)

本文适用于 Windows / macOS 桌面客户端与 iOS 客户端，最初按 v2.2.4 的功能与配置编写；具体入口以当前客户端显示为准，iOS 版不同的地方单独注明。先完成基础 NovelAI 生图，再逐项启用可选服务。

<a id="install"></a>
## 1. 下载并打开客户端

从[首页下载表](../../README.md#download)选择安装包，或直接进入 [GitHub 最新发行版](https://github.com/OldLi1337/novelai-image-desktop/releases/latest)。下载的是对应平台安装包，不是发行页底部的 Source code。

| 平台 | 打开方式 |
| --- | --- |
| Windows 安装版 | 运行带 `Setup` 的 `.exe`，按向导选择路径和快捷方式 |
| Windows 便携版 | 直接运行不带 `Setup` 的 `.exe`；首次解压可能需要等待 |
| macOS | 打开 DMG 并将应用拖入「应用程序」，或解压 ZIP。当前版本未签名、未公证；若系统拦截，请核对下载来源，并按 macOS 提供的应用打开流程处理 |
| iOS（iPhone / iPad） | 下载文件名含 `ios-unsigned` 的未签名 IPA，用自己的 Apple ID 签名后安装，见下方 [iOS：自行签名后安装](#ios) |

Windows 安装包同样未做代码签名，SmartScreen 可能提示“未知发布者”；请只从本仓库的 Latest 下载，并核对发行页显示的附件 SHA256。

<a id="ios"></a>
### iOS：自行签名后安装

iOS 版只提供**未签名的 IPA**：本仓库没有 Apple 开发者证书，IPA 不能直接安装到普通 iPhone / iPad，下载文件本身也不等于已经安装。需要用自己的 Apple ID 签名后安装：

1. 在电脑上安装 [AltStore](https://altstore.io/) 或 [Sideloadly](https://sideloadly.io/) 等侧载工具，按工具的说明连接 iPhone / iPad。
2. 从 [Latest](https://github.com/OldLi1337/novelai-image-desktop/releases/latest) 下载文件名含 `ios-unsigned` 的 `.ipa`。
3. 在侧载工具中选择这个 IPA，用自己的 Apple ID 签名并安装。
4. iOS 16 及以上需要在「设置 → 隐私与安全性」打开「开发者模式」并按提示重启；首次打开时如果提示不受信任的开发者，到「设置 → 通用 → VPN 与设备管理」信任自己的 Apple ID。

- **免费 Apple ID 的签名 7 天后过期**，过期后应用无法打开，用侧载工具重新签名即可，应用数据仍在（AltStore 可在电脑与设备连着同一 Wi-Fi 时自动续签）。用付费的 Apple 开发者账号签名可用一年。
- 签名由你自己的工具和 Apple ID 完成；本项目不提供签名服务，应用本身也不会要求 Apple ID。

普通使用者无需克隆仓库或执行 `npm install`；这些步骤属于[开发者指南](./DEVELOPMENT.md)。

<a id="token"></a>
## 2. 配置 NovelAI Token

1. 准备自己的 NovelAI 账号，确认对应图像模型的使用权限和可用额度。
2. 打开客户端「设置 → API 配置」，按照软件内的图文教程获取 **Persistent API Token**。
3. 将 Token 粘贴到 NovelAI 配置项，不要粘贴浏览器 Cookie，也不要把其他模型服务的 API Key 当作 NovelAI Token。
4. 点击「保存账号」完成只读验证，再用「刷新积分」确认账号连接状态与余额。

iOS 版的账号在「设置」或「生成」页顶部的账号栏：点「管理」进入「API 账号管理」，在「添加账号」中选择「官方 Token」，粘贴 Persistent API Token 后点「验证并保存账号」，同样只做只读验证。

Token 属于账号凭据，请只放在本机配置中，不要贴到 Issue、截图或聊天群。

### 网络怎么选

默认使用「自动跟随系统代理 / VPN」。系统代理或 PAC 按请求地址选择线路，TUN / 虚拟网卡模式由系统路由接管。只有选择手动代理模式时才需要填写 HTTP / SOCKS5 地址。

<a id="first-image"></a>
## 3. 生成并找到图片

1. 进入「生成 → 文生图」，选择账号可用模型。不同模型支持的参数可能不同，以软件当前显示为准。
2. 输入下面这段简单提示词，暂时保留默认参数，张数设为 1。
3. 确认尺寸与预计费用，再点击生成。不要在等待期间反复提交。
4. 使用顶部「输出目录」查看文件，或在右侧历史与素材中查看结果。iOS 版在「图库」中查看；打开「设置」里的「自动保存到系统相册」后，生成的图片也会存进系统相册。

```text
1girl, solo, blue hair, blue eyes, white dress, garden, sunlight, smile
```

![生成工作台的实际布局，v2.0.1 截图](../assets/readme/workbench-light.png)

*上图来自 2026-08-30 的 v2.0.1 界面取证；新版导航与部分控件有所变化。*

第一次成功后，可复用历史参数并固定 Seed，只修改一个标签来观察变化；也可将已有图片送入图生图或重绘。

<a id="optional"></a>
## 4. 按需配置扩展能力

| 想使用的能力 | 额外配置 | 检查方法 |
| --- | --- | --- |
| 图片反推 | 「设置 → AI 反推」中的视觉模型 API 地址、Key 与模型 | 检测接口并选择支持图片输入的模型，先用一张简单图片测试 |
| 提示词转换 | 「设置 → 转换 API」中的文本模型配置 | 检测接口后转换一段短描述 |
| 中文翻译 | 设置中选择谷歌翻译或配置百度翻译 APP ID / 密钥 | 尝试翻译一段短提示词，确认网络或服务凭据可用 |
| 扩展标签检索 | 提示词 / 补全中的 Tag / MCP 服务 | 按所用服务配置地址和传输方式；本地词库可先单独使用 |

反推与转换可以独立配置；自定义 JSON 预设也可导入、重命名和删除。模型服务的 Key 不会替代 NovelAI 生图 Token。

<a id="updates"></a>
## 5. 保存、备份与更新

- **Windows 共享数据**：安装版与便携版均使用 `%APPDATA%\novelai-image-desktop\`。便携版不是零痕迹模式；图片还可能位于自定义输出目录。
- **先备份再迁移**：重要作品单独备份。跨电脑迁移前同时检查配置目录、输出目录与预设导出文件，不要只复制程序。已保存的 NovelAI 账户与各类 API Key 都按本机加密，直接复制配置目录后，需要在新电脑的账户管理中删除并重新添加账户、重新填写 API Key；在「设置 → 备份与恢复 → 数据导入与导出」导出后到新电脑导入，则会一并迁移账户（导入时会联网重新验证）。
- **软件内不提供更新**：新版本统一从 [GitHub Latest](https://github.com/OldLi1337/novelai-image-desktop/releases/latest) 手动下载，软件不会检查或自动安装更新。
- **Windows 安装版**：下载新的带 `Setup` 的安装包并运行安装；安装前先备份设置与作品。
- **Windows 便携版**：手动下载新包替换旧的 `.exe`。
- **macOS**：下载新的 DMG 或 ZIP，按第 1 步的方式替换旧版应用。
- **iOS**：下载新的 IPA，用同一个侧载工具和 Apple ID 签名安装即可覆盖旧版并保留数据。换工具或 Apple ID 可能会装成另一个应用，旧数据不会自动带过去；换之前先在「设置 → 数据导入、导出与自动备份」导出 `.naisbackup`（与桌面版通用）。

<a id="troubleshooting"></a>
## 连接或生成失败时

| 现象 | 优先检查 |
| --- | --- |
| Token 验证失败或 HTTP 401 | 凭据属于哪一个服务、是否粘贴完整、是否过期；重新验证对应配置 |
| 余额不足或模型不可用 | NovelAI 账号权限、额度与本次尺寸 / 张数；实际状态以官方为准 |
| 反推失败，但转换成功 | 视觉 API 是否支持图片输入、模型名称与接口地址是否匹配 |
| 连接超时、连接重置 | 系统代理 / VPN、手动代理地址、对应服务可达性 |
| 超时后不确定是否已扣费 | 先检查余额、历史和输出目录，再决定重试，避免重复生成 |
| 图生图尺寸变化 | 软件会适配有效的 64 倍数尺寸；提交前查看最终宽高 |
| 原数据读取不到提示词 | 图片可能没有嵌入元数据，或经平台压缩后被移除；优先使用原始图片文件 |
| iOS 应用打不开 | 签名是否已过期（免费 Apple ID 为 7 天），用侧载工具重新签名；iOS 16 及以上确认已打开「开发者模式」 |

反馈时提供软件版本、系统、功能入口、复现步骤和脱敏错误信息：[提交 Issue](https://github.com/OldLi1337/novelai-image-desktop/issues/new)。
